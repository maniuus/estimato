Pendahuluan

Selamat datang di dokumentasi panduan resmi **Estimato**. Estimato adalah aplikasi desktop khusus konstruksi yang dibangun untuk menyusun estimasi anggaran biaya (RAB) secara taktis, fleksibel, dan terstruktur.

Berbeda dengan spreadsheet konvensional yang rentan terhadap kesalahan formula referensi sel, Estimato memisahkan data komponen biaya global dengan struktur pekerjaan dinamis, meminimalkan human-error secara signifikan.

Fitur Utama:

  • Penyusunan WBS Modular: Struktur bertingkat yang rapi memudahkan pengorganisasian kelompok pekerjaan utama dan sub-pekerjaan.
  • Library AHS Terpadu: Kelola koefisien komponen AHS SNI Anda di satu perpustakaan pusat.
  • Project Price Override: Sesuaikan harga material khusus untuk proyek tertentu tanpa merusak harga master data library global.
  • Satu Klik Ekspor Excel: Dapatkan dokumen rekapitulasi, harga satuan, dan kebutuhan bahan yang rapi dan profesional untuk langsung diserahkan kepada klien.

Alur Kerja Estimator

Untuk memulai estimasi di aplikasi Estimato, ikuti 4 langkah alur kerja standar berikut:

  1. Konfigurasi Pengaturan Global: Masuk ke tab Pengaturan untuk mendaftarkan nama instansi perencana, direktur penandatangan, default PPN, serta logo resmi perusahaan.
  2. Buat Proyek Baru: Klik tombol "Buat Proyek Baru" di Dashboard. Anda dapat memilih template struktur pekerjaan kosong atau template standar (seperti pembangunan rumah atau renovasi kamar mandi).
  3. Susun WBS & Input Volume: Tambahkan sub-pekerjaan dan sambungkan dengan jenis analisis AHS yang sesuai. Ketikkan nilai volume aktual pekerjaan lapangan.
  4. Ekspor Dokumen Penawaran: Masuk ke tab Laporan untuk memeriksa kalkulasi akhir RAB dan klik ekspor Excel untuk mengunduh laporan penawaran resmi.
Tips: Anda bisa melakukan kustomisasi harga material langsung dari tab "Harga Proyek" apabila supplier lokal memberikan harga khusus untuk proyek tersebut.

Work Breakdown Structure (WBS)

Struktur Pekerjaan (WBS) adalah dasar dari penyusunan RAB di Estimato. Dengan struktur ini, proyek dipecah menjadi bagian-bagian yang lebih kecil secara hierarkis.

Level Hierarki Pekerjaan:

  • Level 1 (Grup Pekerjaan Utama): Contohnya Pekerjaan Persiapan, Pekerjaan Struktur, Pekerjaan Atap. Grup ini bertindak sebagai wadah besar dan tidak memiliki volume langsung.
  • Level 2 (Sub-Pekerjaan / Butir Pekerjaan): Pekerjaan detail seperti "Pemasangan Dinding Bata Merah 1:4". Butir inilah yang memiliki nilai volume aktual (m²), koefisien, dan tautan ke analisis AHS.

Cara Menghubungkan AHS ke Item Pekerjaan:

Pada baris pekerjaan di tabel input RAB, klik tombol "Pilih AHS". Cari kode AHS (misalnya A.4.4.1.9) dari jendela pop-up library dan hubungkan. Harga satuan pekerjaan (HSP) akan otomatis terkalkulasi berdasarkan harga satuan komponen AHS dikalikan koefisien masing-masing.

Analisa Harga Satuan (AHS)

Setiap analisis harga satuan pekerjaan (AHS) terdiri dari tiga kelompok komponen biaya dasar:

  1. Tenaga Kerja (A): Pekerja, Tukang, Kepala Tukang, Mandor.
  2. Bahan / Material (B): Semen, bata merah, pasir pasang, kayu perancah, besi beton, dll.
  3. Alat (C): Sewa mixer molen, vibrator, sewa scaffolding, dll.

Rumus Perhitungan Harga Satuan Pekerjaan (HSP):

Estimato menghitung harga satuan pekerjaan menggunakan formula baku sebagai berikut:

Subtotal Tenaga Kerja (A) = Σ (Koefisien Tenaga x Upah Harian) Subtotal Bahan (B) = Σ (Koefisien Bahan x Harga Satuan Bahan) Subtotal Alat (C) = Σ (Koefisien Alat x Harga Sewa Harian) HSP Sebelum Overhead = Subtotal A + Subtotal B + Subtotal C Overhead & Profit (%) = HSP Sebelum Overhead x Persentase Overhead (misal: 10%) Harga Satuan Pekerjaan = HSP Sebelum Overhead + Overhead & Profit

Manajemen Master Data

Master Data Library bertindak sebagai gudang referensi harga tunggal untuk seluruh proyek Anda. Anda dapat mengelola daftar harga material global, upah tenaga kerja regional, dan biaya sewa alat dari tab "Master Data" di sidebar.

Perbedaan Harga Global dan Harga Proyek:

  • Harga Global: Harga default yang berlaku saat pertama kali AHS dihubungkan ke proyek baru (misal: harga semen kupang Rp75.000/sak).
  • Harga Proyek (Override): Perubahan harga material khusus di dalam proyek tertentu (misal: karena lokasi proyek di luar kota, harga semen naik menjadi Rp80.000/sak). Merubah harga proyek ini tidak akan merubah harga Rp75.000 di database global Anda.

Backup & Restore Database

Untuk mengamankan data proyek dan library AHS Anda dari kerusakan sistem atau ketika Anda ingin memindahkan data ke komputer lain, gunakan fitur pemeliharaan database.

Langkah Melakukan Backup:

  1. Masuk ke halaman Pengaturan.
  2. Temukan panel Backup Database di bagian bawah halaman.
  3. Klik tombol "Backup Database". Pilih lokasi penyimpanan berkas cadangan (.sqlite) di komputer Anda.
Perhatian: Simpan berkas hasil backup Anda dengan aman. Berkas cadangan memuat seluruh daftar master data library, database AHS, serta riwayat proyek RAB Anda.
